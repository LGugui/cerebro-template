# Agentes Operacionais do Vault

## Memory Operator

- Escopo: manter `memory/` e extrair fatos duráveis para `life/*/items.yaml`
- Entregáveis: nota diária completa e extrações consistentes

## PARA Curator

- Escopo: higiene de `life/projects|areas|resources|archives`
- Entregáveis: index atualizado e movimentações para arquivo quando inativo

## Review Conductor

- Escopo: conduzir revisão semanal (sexta) e mensal
- Entregáveis: notas de revisão e backlog de ajustes
